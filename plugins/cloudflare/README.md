# cloudflare

Cloudflare Workers platform skills for Claude Code.

## Skills

| Skill | Purpose |
|-------|---------|
| `cf-workers` | Module exports, request handling, env bindings, routing |
| `cf-workers-ai` | Edge model inference, text generation, embeddings |
| `cf-hono` | Hono routing, middleware, typed bindings |
| `cf-kv` | KV storage, caching, TTL, namespaces |
| `cf-durable-objects` | Stateful workflows, WebSockets, coordination |

## Install

```
/plugin marketplace add mpazaryna/agentic-factory
/plugin install cloudflare@agentic-factory
```

## Update

When skills are updated in the source repo, reinstall to get the latest:

```
/plugin install cloudflare@agentic-factory
```
